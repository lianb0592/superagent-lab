# superagent-lab

Playground repository for testing a ZCode-hosted port of
[deepseek-ai/dsh-superagent-prototype](https://github.com/deepseek-ai/dsh-superagent-prototype).

The agent watches this repository. To give it work, open an issue or comment
and mention `@lianb0592` with a specific, small change request.

Example: `@lianb0592 please change the greeting in hello.txt to say "good morning"`
